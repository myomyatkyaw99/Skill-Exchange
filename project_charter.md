# Project Charter

## Project Title

Campus Skill Swap

## Project Overview

Campus Skill Swap is a website designed to help university students share and learn skills from each other. Students can offer skills they know and find other students who can teach skills they want to learn.

## Problem Statement

Many university students have useful skills but do not have an easy platform to share or teach them. At the same time, students may want to learn new skills but cannot always afford paid courses or find suitable teachers.

## Project Goal

The goal of Campus Skill Swap is to create a simple and accessible platform where students can connect with other students to learn, teach, and exchange skills.

## Target Users

The main users of the website are university students who want to:

- Learn new skills

- Teach skills they already know

- Connect with students who have similar interests

- Exchange skills without relying on expensive courses

## Key Features

- Student skill profiles

- Search for skills

- Skill matching

- Skill categories

- Skill exchange between students

- Campus-based connections

## Project Scope

The project will focus on designing and developing a prototype website that demonstrates the main functions of a campus skill-sharing platform.

## Expected Outcome

The expected outcome is a functional website prototype that demonstrates how university students can find, share, and exchange skills with other students on campus.

## Project Success Criteria

The project will be considered successful if:

- Students can understand the purpose of the platform.

- Users can search for skills.

- The website clearly presents its main features.

- The website is easy to navigate.

- The project files and documentation are available in a public GitHub repository.
