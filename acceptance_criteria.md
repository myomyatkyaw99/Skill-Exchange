# Acceptance Criteria

## Project Title

Campus Skill Swap

The project will be accepted when the following criteria are met:

### AC1 - Website Accessibility

- The website opens successfully in a modern web browser.

- All main sections are visible and easy to understand.

### AC2 - Find a Skill

- The user can click the "Find a Skill" button.

- The skill search section appears.

- The user can enter a skill such as Python.

- The user can click "Search".

- A matching result or appropriate message is displayed.

### AC3 - Share a Skill

- The user can click the "Share Your Skill" button.

- The website provides a response explaining that the feature is available or planned.

### AC4 - User Experience

- Navigation and buttons are clearly displayed.

- The website uses consistent formatting and readable text.

- Users can understand the purpose of the platform without additional instructions.

### AC5 - Project Documentation

- The Project Charter is included in the `docs` folder.

- The Requirements Specification is included in theThe projfolder.

- The Acceptance Criteria document is included in thee projecfolder.

- The Database Design document is included in the

The prfolder.

### AC6 - GitHub Submission

- All project files are uploaded to GitHub.

- The GitHub repository is publicly accessible.

- The submitted GitHub link opens the project repository successfully.
