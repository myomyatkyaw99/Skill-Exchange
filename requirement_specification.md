# Requirements Specification

## Project Title

Campus Skill Swap

## 1. Functional Requirements

### FR1 - Student Profiles

The system shall allow students to create profiles containing their skills, interests, university, major, and availability.

### FR2 - Find a Skill

The system shall allow students to search for skills they want to learn.

### FR3 - Share a Skill

The system shall allow students to list skills they can teach or share with other students.

### FR4 - Skill Matching

The system shall help students find other students who can teach the skills they want to learn.

### FR5 - Skill Categories

The system shall organize skills into categories to make searching easier.

### FR6 - Campus Connection

The system shall focus on connecting students within the same university or campus.

## 2. Non-Functional Requirements

### NFR1 - Usability

The website should be simple and easy for university students to navigate.

### NFR2 - Accessibility

The main features and information should be clearly visible and understandable.

### NFR3 - Performance

The website should load quickly and respond to user actions without unnecessary delays.

### NFR4 - Compatibility

The website should work on common modern web browsers.

### NFR5 - Maintainability

The project code should be organized into separate HTML, CSS, and JavaScript files.

## 3. User Requirements

Students should be able to:

- View the purpose of the Campus Skill Swap platform.

- Search for skills they want to learn.

- Share skills they can teach.

- Find students with similar interests.

- Connect with students on their campus.

## 4. Project Constraints

The current project is a prototype. Advanced features such as real-time messaging, user authentication, and a complete database may not be fully implemented in the prototype.
